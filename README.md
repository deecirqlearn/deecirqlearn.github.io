# DEECIRQ starter website

A responsive, static, faceless technology education website starter.

## Preview locally
Open `index.html` in a browser.

## Before publishing
1. Replace `YOUR-BRAND-EMAIL-HERE` in `index.html` with your dedicated brand email.
2. Review all course statements and only keep offers you can actually deliver.
3. Add your logo file if desired; this starter currently uses a text/CSS logo.
4. Check the page on mobile and desktop.

## Publish free with GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a **public** repository named `deecirq.github.io` only if your GitHub username is `deecirq`; otherwise name it `<your-github-username>.github.io` for a user site, or use a project repository.
3. Upload `index.html`, `style.css`, and `script.js` to the repository root.
4. Open repository Settings → Pages.
5. Under Build and deployment, select Deploy from a branch, choose `main` and `/ (root)`, then Save.
6. Wait for the published URL shown in the Pages section.

Note: GitHub Pages on GitHub Free generally requires a public repository. Anything committed there is public. Do not include private contact details, passwords, API keys, employer material, student data, or confidential files. GitHub Pages is static hosting; this starter does not process payments or store form submissions.
